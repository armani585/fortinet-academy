Glossaire

GLOSSAIRE

Les termes essentiels à connaître

Règle de pare-feu (Firewall Policy)

Règle qui définit quels flux sont autorisés ou refusés selon les interfaces, sources, destinations, services et profils de sécurité.

Session

État d’une connexion suivi par le FortiGate. Une session permet au pare-feu stateful de reconnaître les paquets appartenant à un flux déjà établi.

NAT

Traduction d’adresses réseau. Le SNAT modifie généralement l’adresse source ; le DNAT ou VIP sert notamment à publier un service interne.

VIP

Virtual IP : objet utilisé pour traduire une adresse ou un port exposé vers une ressource interne.

FSSO

Fortinet Single Sign-On : mécanisme permettant d’associer une identité utilisateur à une adresse IP pour appliquer des règles basées sur l’identité.

VDOM

Virtual Domain : contexte logique isolé disposant notamment de ses propres interfaces, routes et règles.

FortiLink

Mécanisme de gestion qui permet au FortiGate de piloter des FortiSwitch intégrés à l’infrastructure.

ZTNA

Zero Trust Network Access : contrôle d’accès basé sur l’identité, le terminal et sa posture de sécurité.

ADOM

Administrative Domain : domaine administratif utilisé notamment dans FortiManager et FortiAnalyzer pour séparer des périmètres.

Debug Flow

Outil de diagnostic FortiOS qui permet de comprendre les décisions prises lors du traitement d’un flux réseau.
