Questions sur la formation

Faut-il déjà connaître Fortinet ?

Non. Le cursus commence par les fondamentaux réseau et la logique d’un pare-feu stateful avant d’aborder les fonctions avancées.

La formation montre-t-elle la GUI FortiOS ?

Oui. Les notions importantes sont reliées aux menus FortiOS afin de savoir où configurer et où vérifier.

Y a-t-il des commandes CLI ?

Oui. La CLI est utilisée pour les vérifications, le routage, les sessions, les VPN, le sniffer, le debug et les diagnostics avancés.

Le contenu est-il orienté entreprise ?

Oui. Sauvegardes, haute disponibilité, supervision, multi-sites, changements maîtrisés et diagnostic de production font partie du parcours.

Est-ce uniquement du FortiGate ?

Non. Le cursus aborde aussi FortiManager, FortiAnalyzer, FortiSwitch, FortiAP, FortiClient EMS, FortiGuard et ZTNA.

Peut-on s’en servir pour préparer une certification Fortinet ?

Oui pour consolider les concepts et la pratique, mais le contenu privilégie la compréhension opérationnelle plutôt que la mémorisation de réponses d’examen.

Comment travailler les incidents ?

Toujours partir du symptôme, suivre le chemin du flux, collecter une preuve avec les journaux ou la CLI, corriger une seule cause puis valider.

Utiliser les cours et les exercices

Les labs exécutent-ils FortiOS dans le navigateur ?

Non. Ils proposent un montage et des procédures à reproduire dans ton laboratoire, ou des dossiers fictifs à analyser sans matériel. Les commandes n’ont pas été exécutées sur un équipement FortiGate pendant la création du site.

Que sauvegarde la progression ?

Le navigateur conserve les modules marqués comme lus et le dernier score validé de chaque quiz. Les réponses saisies ne sont pas conservées. Tu peux tout effacer depuis Parcours. Si le stockage est indisponible, les activités restent utilisables pendant la session.

Quelle version dois-je utiliser ?

Le parcours explique les principes de FortiOS 7.6 et cite les versions des documents. Choisis ton build avec la documentation de ton modèle, les notes de version et les contraintes de ton environnement. Le cours ne recommande pas une version de production universelle.
