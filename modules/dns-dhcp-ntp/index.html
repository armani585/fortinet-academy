MODULE 16 · Production · 45 MIN ESTIMÉES

Services DNS, DHCP et NTP

Isoler résolution de noms, attribution d’adresse et synchronisation horaire.

Prérequis : Modules 2 et 6.

01 · Comprendre02 · Approfondir03 · AppliquerRepères GUI / CLIExercice corrigéQuizSources

LEÇON 1 / 3

DHCP fournit des paramètres

Un bail associe une adresse au client pour une durée et transmet notamment passerelle et DNS. Si l’adresse est correcte mais le résolveur erroné, le poste peut joindre une IP sans joindre un nom. Un relais transporte la demande vers un serveur situé ailleurs : adresse du relais, routage et politiques du trajet font alors partie du diagnostic.

LEÇON 2 / 3

DNS dépend de l’émetteur

Le FortiGate résout des noms pour ses propres services ; les postes utilisent les résolveurs reçus ou configurés. Ce ne sont pas nécessairement les mêmes. Un FortiGate capable de résoudre un nom ne prouve donc pas que le poste le peut. Une réponse négative, une absence de réponse et une adresse incorrecte sont trois résultats distincts. Compare les résultats avec le résolveur réellement utilisé.

LEÇON 3 / 3

L’heure relie les événements

NTP permet de synchroniser les horloges ; le fuseau détermine leur affichage. Les journaux, certificats et mécanismes d’authentification deviennent difficiles à corréler avec une heure incorrecte. Contrôle source de temps, état de synchronisation et dérive. Une correction de fuseau ne répare pas nécessairement un décalage de l’horloge système.

Se repérer dans FortiOS

Dans la GUI

Network → DNS et Interfaces pour DNS/DHCP ; paramètres de temps système selon la version ; Dashboard → Network pour les baux.

Dans la CLI

show system dns
show system dhcp server
show system ntp
diagnose sys ntp status

Lecture seule. Compare la configuration aux paramètres réellement reçus sur le poste.

Exemple expliqué

Le navigateur ne trouve pas app.lab.example, mais le serveur est joignable à 10.10.20.10. Le poste interroge un résolveur qui ne connaît pas la zone interne : le test IP a isolé un problème de noms, pas validé HTTPS.

À toi de pratiquer

Travaille dans un laboratoire isolé. Si tu n’as pas le matériel requis, rédige les observations attendues ; cela ne remplace pas une validation réelle.

  1. Relève IP, masque, passerelle et DNS sur un poste de laboratoire.
  2. Compare résolution d’un nom interne depuis le poste et depuis le service concerné.
  3. Vérifie l’heure du poste, du FortiGate et du collecteur de logs ; rapproche un même événement.
Afficher le corrigé de l’exercice

Le rapport doit distinguer paramètres DHCP, réponse DNS et synchronisation NTP. Après correction du résolveur, valide à nouveau le service par son nom et son protocole réel.

Erreur fréquente

Remplacer tous les DNS par un résolveur public alors que les noms internes doivent être résolus par l’annuaire de l’entreprise.

VÉRIFIER SES ACQUIS

Quiz du module 16

Trois questions, un point par réponse correcte. Tu peux réessayer sans limite. Une réponse non renseignée est signalée séparément ; elle ne rapporte pas de point.

1. Une résolution réussie sur FortiGate prouve-t-elle celle du poste ?

2. Quel protocole synchronise les horloges ?

3. Quel paramètre DHCP influence directement la résolution des noms ?

Consulter le corrigé du quiz

1. Une résolution réussie sur FortiGate prouve-t-elle celle du poste ?
Réponse : Non. Les deux peuvent utiliser des résolveurs différents.

2. Quel protocole synchronise les horloges ?
Réponse : ntp. NTP synchronise l’heure ; le fuseau ne fait que modifier son affichage.

3. Quel paramètre DHCP influence directement la résolution des noms ?
Réponse : Le serveur DNS. Le résolveur fourni doit connaître les zones nécessaires.
